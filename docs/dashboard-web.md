# 3. Frontend Web Deployment

## 3.1 Overview

The **Mara Guard Dashboard** is the web interface used by rangers to monitor lion activity, field devices, battery levels, alerts, and system status.

It is built using **Next.js, React, TypeScript, Tailwind CSS, MQTT, and Recharts**.

## 3.2 Main Dashboard Functions

The Dashboard provides:

- **Lion Detection Monitoring** – Displays detected lion activity and detection counts.
- **Battery Monitoring** – Shows the battery status of solar-powered field devices.
- **System Monitoring** – Displays the status of connected devices and system health.
- **Historical Information** – Allows users to view previous detection and system data.
- **Alerts** – Provides information about important detection and monitoring events.
